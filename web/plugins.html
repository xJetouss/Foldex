Plugin API.
Your commands in Foldex.

Plugin-API.
Deine Befehle in Foldex.

Add your own commands to the right-click menu and the command palette (Ctrl+Space). A command runs a program or script with the selected files – the output shows up in the status bar or in a window. No need to rebuild Foldex.

Füge dem Rechtsklick-Menü und der Befehlspalette (Strg+Leertaste) eigene Befehle hinzu. Ein Befehl startet ein Programm oder Skript mit den markierten Dateien – die Ausgabe erscheint in der Statusleiste oder in einem Fenster. Foldex muss dafür nicht neu gebaut werden.

Quick startSchnellstart

  1. Open Settings → Plugins in Foldex and click Create example plugin.
  2. Foldex opens the folder plugins\beispiel with a plugin.json.
  3. Edit it, click Reload – the commands appear in the right-click menu.
  1. In Foldex Einstellungen → Plugins öffnen und Beispiel-Plugin anlegen klicken.
  2. Foldex öffnet den Ordner plugins\beispiel mit einer plugin.json.
  3. Bearbeiten, Neu laden klicken – die Befehle stehen im Rechtsklick-Menü.

Where plugins liveWo Plugins liegen

Every plugin is a folder with a plugin.json inside the plugin folder:

Jedes Plugin ist ein Ordner mit einer plugin.json im Plugin-Ordner:

%APPDATA%\foldex\plugins\        (Linux: ~/.config/foldex/plugins/)(Linux: ~/.config/foldex/plugins/)
├── bilder\
│   ├── plugin.json
│   └── verkleinern.ps1
└── git-helfer\
    └── plugin.json

Settings → Plugins lists all plugins, turns them on and off and reloads them. The environment variable FOLDEX_PLUGINS_DIR points Foldex to another folder (handy while developing).

Einstellungen → Plugins zeigt alle Plugins, schaltet sie ein und aus und lädt sie neu. Mit der Umgebungsvariable FOLDEX_PLUGINS_DIR nutzt Foldex einen anderen Ordner (praktisch beim Entwickeln).

plugin.json

{
  "name": "Resize images",
  "version": "1.0",
  "author": "Jan",
  "description": "Shrinks photos with ImageMagick",
  "api": 1,
  "commands": [
    {
      "id": "small",
      "title": "Resize to 1080 px",
      "when": ["file"],
      "extensions": ["jpg", "png"],
      "each": true,
      "run": "magick",
      "args": ["{file}", "-resize", "1080x1080", "{parent}/{stem}-small.{ext}"],
      "output": "status",
      "refresh": true,
      "icon": "image"
    }
  ]
}

ScriptsSkripte

If run ends in .ps1, .bat/.cmd, .py, .js or .sh, Foldex starts the matching interpreter (powershell -File, cmd /C, python, node, bash). The paths arrive as arguments – $args in PowerShell, sys.argv[1:] in Python.

Endet run auf .ps1, .bat/.cmd, .py, .js oder .sh, startet Foldex den passenden Interpreter (powershell -File, cmd /C, python, node, bash). Die Pfade kommen als Argumente an – $args in PowerShell, sys.argv[1:] in Python.

Commands with status or window output run in the background without a console window and are stopped after 10 minutes. A non-zero exit code counts as an error and opens the output window.

Befehle mit Ausgabe status oder window laufen ohne Konsolenfenster im Hintergrund und werden nach 10 Minuten beendet. Ein Exit-Code ungleich 0 gilt als Fehler und öffnet das Ausgabefenster.

Windows, Linux and AndroidWindows, Linux und Android

A command can have its own run/args per system: windows, linux, android or unix (Linux and Android). Commands without a program for the running system are hidden there. On Android, .sh scripts run with the system shell (Toybox: find, sed, sort, sha256sum, du, wc …).

Ein Befehl kann je System ein eigenes run/args haben: windows, linux, android oder unix (Linux und Android). Befehle ohne Programm für das laufende System werden dort ausgeblendet. Auf Android laufen .sh-Skripte mit der System-Shell (Toybox: find, sed, sort, sha256sum, du, wc …).

{ "id": "sha256", "title": "SHA-256", "when": ["file"],
  "run": "hash.ps1", "args": ["{files}"],
  "unix": { "run": "hash.sh" },
  "output": "window" }

An icon.png (square, e.g. 128 × 128) in the plugin folder is shown next to the plugin in the settings.

Ein icon.png (quadratisch, z. B. 128 × 128) im Plugin-Ordner erscheint in den Einstellungen neben dem Plugin.

CatalogKatalog

Settings → Plugins → Catalog lists the plugins from the plugins/ folder of the Foldex repository – with logo, one-click Install and Remove, in the desktop app and on Android. plugins/index.json names each plugin's id, name, description, version, author, its files and optionally platforms.

Einstellungen → Plugins → Katalog zeigt die Plugins aus dem Ordner plugins/ des Foldex-Repositorys – mit Logo, Installieren und Entfernen per Klick, in der Desktop-App und auf Android. plugins/index.json nennt je Plugin id, name, description, version, author, die Dateien (files) und optional platforms.

ExamplesBeispiele

Copy paths as a list

Pfade als Liste kopieren

{ "id": "paths", "title": "Copy paths", "when": ["file", "folder"],
  "run": "copy.ps1", "args": ["{files}"], "output": "status" }

# copy.ps1
$args | Set-Clipboard
"$($args.Count) path(s) copied"

Last commits of a folder

Letzte Commits eines Ordners

{ "id": "log", "title": "Last commits", "when": ["background"],
  "run": "git", "args": ["log", "--oneline", "-20"], "output": "window", "icon": "git" }

Merge PDFs

PDFs zusammenfügen

{ "id": "merge", "title": "Merge PDFs", "extensions": ["pdf"],
  "run": "qpdf", "args": ["--empty", "--pages", "{files}", "--", "{dir}/merged.pdf"],
  "refresh": true, "confirm": "Merge the selected PDFs into merged.pdf?" }

SecuritySicherheit

Plugins run with your user rights like any other program. Only install plugins from sources you trust and look at plugin.json and its scripts before turning a plugin on.

Plugins laufen mit deinen Rechten wie jedes andere Programm. Installiere nur Plugins aus Quellen, denen du vertraust, und sieh dir plugin.json und die Skripte vor dem Einschalten an.
